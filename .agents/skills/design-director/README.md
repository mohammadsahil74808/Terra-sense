# Design Director

Design Director skill digital products ke liye bespoke visual identity, art-directed design systems, typography hierarchy, functional color tokens, spacing grid, aur layout strategy establish karti hai.

---

## 🧠 Ye Skill Kya Hai?

Ye skill ek senior product designer aur visual design director ki tarah operate karti hai. Iska kaam sirf random colors chuna nahi hai, balki project ki actual audience, brand, content, aur platform ko analyze karke implementation se pehle ek complete, non-generic design direction foundation tayyar karna hai.

---

## 🎯 Iska Main Kaam Kya Hai?

* **Visual Identity & Brand Tone**: Project ke purpose ke according custom visual personality define karti hai.
* **Typography System**: Ratio-based typographic scale (Google Fonts like Inter, Outfit, JetBrains Mono) with fluid `clamp()` sizing define karti hai.
* **Functional Color System**: HSL/RGB tailored semantic color tokens (Primary, Surface, Contrast, Borders) setup karti hai (plain browser blue/red avoid karti hai).
* **Spacing Grid & Component Philosophy**: 4px/8px base spacing grid, border radius system, elevation levels, aur surface treatments determine karti hai.
* **Content-First Layout Strategy**: Content hierarchy ke according grid composition aur visual rhythm plan karti hai.

---

## ⚡ Kab Use Hogi?

* Jab kisi naye web ya Flutter project ki visual identity aur design system build karni ho.
* Jab application ka UI generic ya mismatched components se bhara hua ho.
* Coding start karne se pehle complete visual foundation tayyar karne ke liye.
* Product redesigns ya visual brand alignment ke waqt.

```text
Product & Audience Analysis
            ↓

            ↓

            ↓

            ↓
15-Point Design Direction Plan Output
```

---

## 📥 Isko Kya Input Chahiye?

* **Product Requirements**: App/Website ka type (Web vs Flutter), product domain (Fintech, SaaS, AI, etc.).
* **Target Audience & Brand Intent**: Luxury, precision, friendly, executive, minimal tone preferences.
* **Content Inventory**: Headings, features, call-to-actions.

---

## 📤 Ye Kya Output Degi?

* Detailed **15-Point Design Direction Plan** document.
* CSS custom properties (`:root`) / Flutter `ThemeData` token specifications.
* Typographic scale, color contrast rules, spacing tokens, and 8-state component rules.

---

## 🤝 Dusri Skills Ke Saath Relation

* **Anti-AI Design**: Design Director base visual identity establish karta hai, Anti-AI Design layout se generic clichés filter karta hai.
* **3D Experience Director / Motion Director**: Visual identity ke color palette, lighting mood, aur easing curves ke rules transfer hote hain.
* **Premium Web / Premium Flutter**: Production code implement karne ke liye design tokens (`ThemeData` / CSS variables) provide karta hai.

---

## 🧩 Master Orchestrator Mein Iska Role

* Master Orchestrator visual digital product requests ke liye Phase 2 mein `design-director` ko sabse pehle activate karta hai.
* Iska Output baki saare specialists (`3d-experience-director`, `motion-director`, `premium-web`, `premium-flutter`) ke liye visual baseline banta hai.
