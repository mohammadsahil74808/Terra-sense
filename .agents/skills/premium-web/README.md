# Premium Web

Premium Web skill modern web applications aur creative landing pages ke liye production-ready frontend architecture (Next.js, Vite, React, Vue, Svelte, HTML/CSS/JS), fluid CSS design tokens, 8-state components, Three.js 3D canvas integration, GSAP/CSS motion choreography, aur 3-Tier progressive enhancement implement karti hai.

---

## 🧠 Ye Skill Kya Hai?

Ye skill ek senior premium web experience architect, creative developer, frontend engineer, aur responsive implementation specialist ki tarah kaam karti hai. Iska main objective visual design direction, motion tokens, 3D canvases, asset pipelines, anti-AI rules, aur performance budgets ko clean, distinctive, fast, aur production-quality web code mein transform karna hai.

---

## 🎯 Iska Main Kaam Kya Hai?

* **3-Tier Progressive Enhancement**:
  - *Tier 1 (Baseline)*: 100% Readable Semantic HTML5 + Vanilla CSS (works without JS).
  - *Tier 2 (Enhanced)*: JS Hydration, state management, interactive drawers, route transitions.
  - *Tier 3 (Premium)*: WebGL / WebGPU 3D spatial visualizer canvas with static image fallbacks.
* **Fluid CSS Token System**: `clamp()` based fluid typography and spacing variables (`--font-size-hero: clamp(2rem, 5vw, 4.5rem)`).
* **8-State Component Matrix**: Components ke saare 8 states (Default, Hover, Focus, Active, Disabled, Loading, Error, Success) correctly render karna.
* **Cross-Director Synthesis**: Design Director ke colors, Motion Director ke GPU-whitelisted CSS properties (`transform`, `opacity`), 3D Experience Director ke WebGL canvas, aur Asset Director ke `<picture>` media tags Synthesize karke production code likhna.
