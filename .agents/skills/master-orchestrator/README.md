# Master Orchestrator

Master Orchestrator skill poore production skills suite ka **central decision-making, workflow coordination, aur quality gate brain** hai. Ye user ke natural language request ko understand karke requirement brief banati hai, exact required specialist skills select karti hai, dependency-aware execution graph manage karti hai, aur `final-product-critic` ke audit findings ko specific specialists tak reroute karwati hai.

---

## 🧠 Ye Skill Kya Hai?

Ye skill ek senior product development master orchestrator, multi-skill systems architect, aur quality gate director ki tarah kaam karti hai. Iska main objective user request se complex multi-skill workflows coordinate karna hai. **User ko individual specialist skills ke naam janne ya mention karne ki koi zaroorat nahi hai.**

---

## 🎯 Iska Main Kaam Kya Hai?

* **Product Category Detection**: User intent analyze karke exact product type identify karti hai:
  - *Web Product*: `premium-web`, `design-director`, `anti-ai-design`, `performance-engineer`, `accessibility-director`, `security-director`, `final-product-critic`.
  - *Flutter Product*: `premium-flutter`, `design-director`, `performance-engineer`, `accessibility-director`, `security-director`, `final-product-critic`.
  - *AI Assistant / Agent*: Platform implementation, `security-director` (Mandatory tool permission gates), `performance-engineer`, `final-product-critic`.
* **Intelligent Skill Selection Engine**: Sirf zaroori skills activate karti hai (e.g. 3D explicitly poocha ho tabhi `3d-experience-director` chalati hai, `premium-web` aur `premium-flutter` ko bina zaroorat ek saath mix nahi karti).
* **Dependency Graph & Parallelization**: Phase-wise execution manage karti hai: Foundation → Visual Design → Parallel Specialists (Assets, Motion, 3D) → Implementation → Audits → Final Critic Gate.
* **Conflict Resolution Hierarchy**: Requirement conflict aane par strict order follow karti hai: User Request > Correctness > Security > Accessibility > Performance > Core UX > Visual Quality > 3D/Motion Spectacle.
* **5 Quality Gates & Critic Fix Loop**: Gate 1 se 4 enforce karne ke baad Gate 5 par `final-product-critic` run karti hai. Agar P0/P1 issues milte hain, toh accurate specialist (e.g. XSS security issue → `security-director`) ko targeted fix ke liye route karti hai.

---

## ⚡ Kab Use Hogi?

* Jab naya complex product ya full-stack application end-to-end build karna ho.
* Jab multiple specialist skills (Design, 3D, Motion, Web/Flutter, Security, Accessibility) ko coordinate karna ho.
* Jab user high-level product request de (e.g. "Build a 3D Web3 fintech landing page").

## 🚫 Ye Skill Kya Nahi Karegi?

* Ye har skill ko blindly ek saath invoke nahi karegi (sirf relevant skills chunti hai).

* Ye P0/P1 issues maujood hone par unfinished product ko ready declare nahi karti.
