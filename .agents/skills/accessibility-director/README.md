# Accessibility Director

Accessibility Director skill applications aur websites ke liye WCAG 2.1 AA compliance, inclusive UX design, screen-reader semantics, keyboard focus traps, 200% font scaling survival, aur 3D/AI text equivalents enforce karti hai.

---

## 🧠 Ye Skill Kya Hai?

Ye skill ek senior accessibility architect, inclusive UX designer, aur accessibility engineer ki tarah kaam karti hai. Iska main objective ye ensure karna hai ki visual experience ko dull ya boring banaye bina product har type ke user (visual, motor, auditory, cognitive, aur situational constraints wale users) ke liye accessible aur operable rahe.

---

## 🎯 Iska Main Kaam Kya Hai?

* **WCAG 2.1 AA Baseline Enforce Karna**: 4.5:1 text contrast ratios, 3:1 UI boundary contrast, aur non-color state indicators design karna.
* **Semantic Structure & ARIA / Semantics**: Semantic HTML5 tags (`<header>`, `<nav>`, `<main>`, `<button>`) aur Flutter `Semantics` widget trees establish karna.
* **Keyboard Navigation & Focus Management**: Full keyboard access (Tab, Space, Enter, Escape), high-contrast 2px visible focus rings, aur modal dialog focus traps setup karna.
* **Touch Target Ergonomics & Text Scaling**: Enforce minimum 48x48px hit areas aur 200% font size scaling par layout text clipping/overflow ko roknna.
* **Complex Feature Fallbacks**: 3D spatial models aur Canvas charts ke liye structured HTML/ARIA text data tables, aur Motion ke liye `prefers-reduced-motion` cross-fades design karna.

---

## ⚡ Kab Use Hogi?

* Jab app/website ka accessibility audit karna ho ya WCAG 2.1 AA compliance achieve karni ho.
* Jab dynamic modals, dropdowns, ya drawers keyboard navigation par stuck ho rahe hon.
* Jab system font size 200% badhane par UI text clip ya overflow ho raha ho.
* Jab complex 3D visualizers, SVGs, ya charts ko screen-reader users ke liye accessible banana ho.

## 📥 Isko Kya Input Chahiye?

* **Codebase & UI Components**: Current HTML, CSS, React, ya Flutter widgets.
* **Target Conformance Level**: Default WCAG 2.1 AA target.
* **Media & 3D Assets**: SVGs, 3D canvases, video links.

---

## 📤 Ye Kya Output Degi?

* Comprehensive **35-Point Accessibility Strategy** document.
* Semantic HTML5 tag refactoring ya Flutter `Semantics` widget wrapping instructions.
* High-contrast CSS `:focus-visible` styling aur 48x48px touch target adjustments.
* Live region controls (`aria-live="polite"`) for streaming AI text responses.

---

## 🤝 Dusri Skills Ke Saath Relation

* **Design Director**: Color contrast ratios (4.5:1) aur visible focus ring themes check karti hai.
* **Motion Director**: `prefers-reduced-motion` settings ke according CSS cross-fades apply karwati hai.
* **3D Experience Director**: 3D scenes ke text-based ARIA data table fallbacks setup karwati hai.
* **Premium Web / Premium Flutter**: Production code mein semantic controls aur focus trap event listeners enforce karti hai.

---

## 🧩 Master Orchestrator Mein Iska Role

* Master Orchestrator har serious production web/mobile app build ke liye `accessibility-director` ko mandatory feature review state par activate karta hai.
* Code implementation ke baad Phase 5 (Production Audits) mein run hoti hai.

## 🚫 Ye Skill Kya Nahi Karegi?

* Ye accessibility achieved bolne ke liye sirf automated scanner (Lighthouse/axe) par rely nahi karegi (manual keyboard & screen reader behavior check karti hai).
* Ye visual design ko boring ya flat nahi banayegi; ye premium UI ke saath accessible fallbacks build karti hai.
