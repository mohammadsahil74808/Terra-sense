# 3D Experience Director

3D Experience Director skill digital applications aur websites ke liye Technology-Agnostic 3D rendering architecture aur real-time graphics experience design karti hai. Ye decide karti hai ki project mein 3D visual use karna kitna zaruri hai, kaunsi rendering technology (Three.js, R3F, WebGL/WebGPU, Flutter 3D ya pre-rendered video/image fallback) use honi chahiye, aur assets ko performance-friendly kaise rakha jaaye.

---

## 🧠 Ye Skill Kya Hai?

Ye skill ek senior 3D experience architect, technical 3D director, aur real-time graphics specialist ki tarah operate karti hai. Iska main purpose sirf random 3D objects float karana nahi hai, balki product requirement ke according ek deliberate, high-quality, aur interactive 3D visual system design karna hai jo user experience ko enhance kare.

---

## 🎯 Iska Main Kaam Kya Hai?

* **3D Necessity Evaluation**: Decide karti hai ki product mein 3D actually useful hai ya 2D static representation sufficient hai.
* **Technology Selection**: Three.js, React Three Fiber, WebGL/WebGPU, Flutter 3D, ya pre-rendered video sequences mein se best rendering stack chunti hai.
* **Asset Pipeline Optimization**: GLB/glTF 3D models ke liye Draco compression, KTX2 texture encoding, aur polygon budget fix karti hai.
* **Camera & Lighting Architecture**: PBR (Physically Based Rendering) materials, dynamic lights, environmental maps, aur camera movement choreography define karti hai.
* **4-Tier Quality Matrix**: High-end GPU se lekar low-end mobile devices ke liye HIGH, MED, LOW, aur 2D poster image FALLBACK levels set karti hai.

---

## ⚡ Kab Use Hogi?

* Jab landing page ya web app mein interactive 3D hero section ya canvas ki zaroorat ho.
* Jab e-commerce platform par 3D product configurators ya spatial visualizers banane hon.
* Jab architecture, science, healthcare, ya automotive product ke liye 3D models showcase karne hon.
* Jab WebGL graphics mobile devices par slow render ho rahe hon aur frame-rate optimization ki zaroorat ho.

## 📥 Isko Kya Input Chahiye?

* **Product Requirements**: Project ka format (Web vs Flutter), target devices.
* **Design Direction**: Design Director ke color tokens, lighting mood, aur spacing rules.
* **3D Assets**: Raw `.gltf`/`.glb` models, texture files, ya asset URLs.
* **Performance Budget**: Target FPS (60 FPS default) aur VRAM limits.

---

## 04 📤 Ye Kya Output Degi?

* Detailed **24-Point 3D Experience Plan** document.
* 3D rendering stack selection (Three.js, R3F, Canvas, Video fallback).
* Draco compression aur KTX2 texture optimization parameters.
* Camera angles, PBR lighting configuration, aur interaction events.
* Low-end device ke liye 2D fallback posters.

---

## 🤝 Dusri Skills Ke Saath Relation

* **Design Director**: Visual identity aur color scheme accept karti hai taaki 3D lighting aur materials brand ke saath match karein.
* **Performance Engineer**: VRAM consumption, draw calls, aur FPS budgets set karne ke liye collaborate karti hai.
* **Asset Director**: GLB/glTF model compression aur asset priority loading control karti hai.
* **Premium Web / Premium Flutter**: Canvas setup, WebGL context loss handling, aur implementation code ke liye instructions deti hai.

---

## 🧩 Master Orchestrator Mein Iska Role

* Orchestrator ise tabhi select karega jab product request mein explicit 3D, WebGL, ya spatial visualizer ki requirement ho.
* Phase 2 (Design Direction) ke baad parallelly Phase 3 mein execute hoti hai.
* Iska output `premium-web` ya `premium-flutter` ko technical canvas setup ke liye hand off hota hai.

## 🚫 Ye Skill Kya Nahi Karegi?

* Ye har website par bina requirement ke floating 3D spheres force nahi karegi.
* Ye complete web application ka HTML/CSS layout khud code nahi karti (woh `premium-web` karega).
* Ye basic image optimization tak limited nahi hai (woh `asset-director` sambhalega).
