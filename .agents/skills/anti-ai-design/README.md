# Anti-AI Design

Anti-AI Design skill websites aur mobile applications se generic AI templates, overused visual clichés, repetitive card grids, purple/cyan glowing blurs, aur stock copy ko remove karke bespoke visual identity establish karti hai.

---

## 🧠 Ye Skill Kya Hai?

Ye skill ek senior visual critic, art director, aur originality auditor ki tarah operate karti hai. Iska main objective products ko "AI boilerplate template" ya common design trends ki copy lagne se rokna hai, aur intentional, human-art-directed design system provide karna hai.

---

## 🎯 Iska Main Kaam Kya Hai?

* **Cliché Detection**: Overused patterns (purple-to-cyan radial gradients, floating glassmorphism cards, random floating 3D orbs, uniform card grids) detect karti hai.
* **Subtraction Audit**: Unnecessary decorative elements ko design se subtract karti hai taaki product clean aur functional lage.
* **1,000 Products Test**: Audit karti hai ki agar logo aur brand name hata diya jaaye, toh kya website kisi doosri brand se alag pehchani ja sakti hai ya nahi.
* **Subtle Grid & Micro-Details**: Generous asymmetrical spacing, 1px solid subtle borders, crisp contrast, aur editorial typography ratios introduce karti hai.

---

## ⚡ Kab Use Hogi?

* Jab landing page ya website generic AI-generated template ya Dribbble cliché jaisi lagne lage.
* Jab hero section mein random purple blur orbs aur repetitive cards Bhare hue hon.
* Jab brand voice aur messaging mein stock, meaningless AI buzzwords ho.
* Customer-facing production websites ke design evaluation ke time.
