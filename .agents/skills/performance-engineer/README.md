# Performance Engineer

Performance Engineer skill web aur Flutter applications ke liye systems-level performance optimization, Core Web Vitals (LCP, INP, CLS), WebGL/3D draw call & VRAM tuning, React/Flutter rebuild narrowing, Dart Isolates, asset loading strategies, aur memory leak prevention handle karti hai.

---

## 🧠 Ye Skill Kya Hai?

Ye skill ek senior performance engineer, frontend performance architect, real-time rendering optimizer, aur mobile performance specialist ki tarah operate karti hai. Iska main objective visual quality, 3D experience, aur rich animations ko blind sacrifice kiye bina application ko fast, smooth, aur low-latency banana hai.

---

## 🎯 Iska Main Kaam Kya Hai?

* **Core Web Vitals Optimization**: LCP < 2.5s, INP < 100ms, aur CLS < 0.1 achieve karwana.
* **Flutter Rebuild & Render Narrowing**: Unnecessary widget rebuilds roknna (`const` constructors, `ValueListenableBuilder`), `RepaintBoundary` use karna, aur heavy tasks ke liye Dart background Isolates (`compute()`) execute karna.
* **WebGL & 3D Optimization**: Draw calls reduce karna, Draco mesh compression, KTX2 GPU textures, aur VRAM memory management budget fix karna.
* **Network & Bundle Optimization**: Code-splitting, tree-shaking, HTTP/3 resource hints (`preconnect`, `preload`), aur aggressive caching strategy plan karna.
* **Memory & Battery Hygiene**: Unused event listeners, controllers (`dispose()`), active timers, aur memory leaks detect aur clear karwana.

---

## ⚡ Kab Use Hogi?

* Jab web app par Lighthouse score low aara ho ya Core Web Vitals (LCP, INP, CLS) fail ho rahe hon.
* Jab Flutter app scroll karne par frame drop (jank) ho raha ho.
* Jab 3D WebGL scenes mobile devices par overheat ya VRAM exhaust kar rahe hon.
* Network payload, bundle size, ya high memory consumption optimize karte waqt.
